# Sources — official, verified

All data on the site is traceable to the official sources below. Every data
table row links to the source backing that row. If a value could not be
confirmed from an official source, it is left blank and flagged unverified.

| Source | Used for | Link |
|--------|----------|------|
| NBA.com — Schedule | Upcoming slate (matchups, times, arenas, NBA Cup groups) | https://www.nba.com/schedule |
| NBA.com — Stats | Statistics portal (per-game, advanced, leaders) | https://www.nba.com/stats/ |
| NBA.com — Injury Report | Official injury report (live statuses — unverified this session) | https://www.nba.com/news/injury-report |
| Basketball-Reference — 2026-27 Standings | Team W/L, PS/G, PA/G, SRS; season leaders | https://www.basketball-reference.com/leagues/NBA_2027_standings.html |
| Basketball-Reference — 2026-27 Schedule | Schedule & results | https://www.basketball-reference.com/leagues/NBA_2027_games.html |
| Basketball-Reference — Boxscore Index 2026-11-12 | Completed games + leaders (verification sample) | https://www.basketball-reference.com/boxscores/index.fcgi?month=11&day=12&year=2026 |
| Basketball-Reference — Home | General reference index | https://www.basketball-reference.com/ |

## Source selection rationale

- **Basketball-Reference** and **NBA.com** are the standard, trusted,
  authoritative sources for NBA statistics, schedule, and standings.
- **No sportsbook / odds source** is used, because no verified odds feed was
  available in this session. Consequently market-comparison values are left
  blank and flagged unverified rather than estimated.
- **No live injury feed** was verified in this session; injury statuses are
  left blank and flagged, pointing to the official NBA.com injury report.
