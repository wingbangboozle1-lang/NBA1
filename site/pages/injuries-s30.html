The rules this page is held to

  • Status map: Out = 0.0, Doubtful = 0.25, Questionable = 0.5, Probable = 0.8, Available = 1.0. Declared in data/derived/injury_impact.json and reused here so two pages cannot disagree about what Questionable means.
  • Minutes source caveat: The ranking is sorted by POINTS per game and is truncated at 50 rows by the capture; if the NBA.com title reads '2026-27 REGULAR SEASON' then its sort key is points, not minutes. A player absent from this table has NO measured minutes here, whatever his true role — so every team's coverage figure below is a lower bound and a 0.00 is never 'healthy'.
  • Not modelled, because no official source exists: games-until-return by injury type; pace change when a creator is out; defensive rating change from a lost rim protector; replacement-player production quality
  • Production transfer: Declared in the committed module as a flat 0.55 of a player's scoring. This session measured the minutes-to-production elasticity directly from official game logs (data/derived/prop_variance.json -> minutes_elasticity: PTS 1.288 +/- 0.296, REB 0.626 +/- 0.367, AST 0.485 +/- 0.488, PRA 0.934 +/- 0.250) and did NOT change the module — changing it would move every published line, which is a decision for the owner, not this session. It is recorded on the Suggestions page as an open option.
