Definition conflict, published for a decision. gap in calendar days between the two games: engine/validate.py sets rest_days = date - last_date and calls a back-to-back rest_days == 1
full days off between them: scripts/originate_horizon.py returns gap - 1 and calls a back-to-back gap == 1, so a back-to-back prints 0
one page says a team has 1 day of rest and another says 0 for the same fact; a reader comparing the two pages cannot tell which is the number Worked example: NOP: last game 2026-11-13, next game 2026-11-14 - horizon page prints rest_days 0 with b2b true; the out-of-sample pages would print 1. This file publishes both quantities: both: gap_days (calendar days between games) and days_off (gap - 1). source
