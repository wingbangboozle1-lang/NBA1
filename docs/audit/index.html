Not verified in this audit

  • Betting lines, odds and prices: no price source was checked.
  • Injury-report rows and player minutes: outside this audit's scope (covered by other sessions' claims).
  • Model outputs (projected totals, spreads and probabilities): only their arithmetic against the stored results was checked.

Method and reproduction

  • Official values were transcribed from fetch-tool reads of the NBA.com pages and stored with the URLs in audit/results/official_scores_2026-11-06_to_12.json and audit/stats/official_team_advanced.json.
  • Run python3 audit/results/check_results.py, python3 audit/stats/check_team_advanced.py, then python3 audit/build_audit_page.py. The page builder refuses to run if either checker reports a mismatch.
  • Reports: audit/results/x01_x02_report.json and audit/stats/x03_report.json.
