What is deliberately absent

  • No sportsbook or odds provider. None was reachable, which is why every ROI assumes −110.
  • No secondary statistics sites. Values that could not be read from an official NBA page were left blank rather than borrowed from an aggregator.
  • No news reporting. Injury statuses come from the league's own report, not from beat writers.

Verification

Two scripts gate this site. verify_data.py checks captured data against its sources (provenance hosts, blank-field accounting, schedule/record reconciliation, pace against possessions, ratings against scoring, the scoring identity, played-game integrity, minutes monotonicity and absence-class consistency). verify_inline.py checks the derived outputs for invented values, false validations, double-counted injuries, unsaturated probabilities and implausible totals.

Current status: verify_data.py returns errors=0 across 15 checks. verify_inline.py passes its derived checks. Both were run against this build.
