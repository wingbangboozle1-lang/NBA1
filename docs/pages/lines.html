Originated Lines

Spreads, totals and moneylines produced by the model for every game on the next three slates, shown next to the naive reference line they are being tested against.

i

"Reference" is a deliberately naive model, not a sportsbook. No book price is published by an NBA-operated source, so none can be linked. The reference is raw net rating + a flat +2.0 home edge for the side, and the two teams' published scoring averages added together for the total. Model gap is the difference between the two models — it is not edge against a market. See F3.

Column notes

Ref spread
Naive reference home spread. Negative = home favoured.
Model spread
Originated home spread: efficiency + shrinkage + home court + rest + availability.
Gap
Model minus reference. Positive = the model likes the home side more than the reference does.
P(home cover)
Probability the home side covers the reference spread, from the fitted margin spread.
P(over)
Probability the game goes over the reference total.
Fair ML
Vig-free American price implied by the model win probability.
Avail. loss
Net-rating points per 100 possessions removed for official injury-report unavailability. A floor — see F2.
