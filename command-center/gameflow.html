Game Flow

Pace, rest, back-to-back and availability context for every upcoming game
as of …

Game flow is about how a game is likely to be shaped: how many possessions, how tired each side is, and whether the rotation is intact. It is derived from official pace and efficiency inputs plus the fitted outcome spread — not from play-by-play, which this repository does not capture.

!

No possession-level metric is published. Runs, quarter splits and timeout-adjusted flow all need play-by-play data. What is here is a pre-game distribution: expected possessions, expected total and margin, and the probability the game stays close.
